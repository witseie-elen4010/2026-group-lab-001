# ADR: Coveralls for Code Coverage Reporting

## Status
Accepted

## Context
We require persistent tracking and pull-request reporting of test coverage to monitor trends and prevent regressions. Jest can generate coverage reports, but it does not persist results or present historical metrics; a third-party service is therefore necessary.

## Decision
Adopt Coveralls for coverage reporting. Rationale:
- Supports Jest's `lcov.info` output and integrates with GitHub Actions.
- Provides PR comments, dashboards, and historical metrics.
- Free for public repositories and requires minimal configuration.
- Mature and appropriate for the project's scale.

Actions taken:
- Added `coveralls` as a development dependency.
- Added a coverage badge to `README.md`.

Note: Coveralls is linked to the repository. The GitHub Actions workflow to run `jest --coverage` and upload results to Coveralls has not yet been configured.

## Consequences
- Once the workflow is configured, CI will upload coverage reports on each push and pull request.
- Coverage metrics and diffs will be available in Coveralls, enabling targeted test improvements and accountability.
- Minimal CI overhead is required to generate and publish reports.
